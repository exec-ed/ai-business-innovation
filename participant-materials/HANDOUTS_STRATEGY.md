---

## Recommended Approach: Hybrid (Print + Digital + Interactive)

### Strategy:
- **Print what they need DURING workshop** (reference, can't lose battery)
- **Digital what they use AFTER workshop** (search, copy-paste prompts)
- **Interactive what requires calculation/input** (checklist, calculator)

---

## Material-by-Material Recommendations

### 1. AI Investment Checklist ⭐ MAKE INTERACTIVE

**Why Interactive:**
- ✅ Scoring calculations (data readiness 0-10)
- ✅ Weighted scores (multiple factors)
- ✅ Auto-recommendations ("Score <7 = invest in data first")
- ✅ Save/print filled checklist
- ✅ Reuse for multiple projects

**Format:** Interactive HTML (like investment calculator)
- Input fields for scores
- Auto-calculates weighted totals
- Red/yellow/green indicators
- Conditional recommendations
- Print results as PDF

**Also Provide:** PDF version for offline use

**When Used:**
- Exercise 3 prep (teams fill out for their pitch)
- Post-workshop (evaluate real AI proposals)

---

### 2. Frameworks Reference Sheet ⭐ PRINT AS BOOKLET

**Why Print:**
- ✅ Quick reference during all exercises
- ✅ No battery/wifi dependency
- ✅ Can annotate during workshop
- ✅ Take-home physical reference
- ✅ Not interactive (just information)

**Format:** Printed booklet (8-12 pages)
- Fold A3 into A4 booklet, OR
- Stapled A4 pages

**Layout:**
- Page 1: Cover + Table of Contents
- Page 2-3: AI Transformation Matrix (with visuals)
- Page 4-5: Data Value Pyramid + Three Horizons
- Page 6-7: AI Investment Model
- Page 8-9: Innovation Adoption Framework
- Page 10: Scale/Pivot/Kill Criteria
- Page 11-12: Quick reference cards

**Also Provide:** Digital PDF on GitHub Pages (for searching later)

**When Used:**
- Throughout entire day (constant reference)
- Take home for desk reference

---

### 3. Strategic Prompting Guide ⭐ DIGITAL HTML BOOKLET

**Why Digital (Not Print):**
- ✅ Need to COPY-PASTE prompts (can't type long prompts manually)
- ✅ Searchable (find specific technique)
- ✅ Linkable (share sections with team)
- ✅ Updates easily (add new prompts later)
- ❌ Don't need during workshop (used post-workshop on Monday)

**Format:** Simple HTML booklet (like a mini-site)
- Clean typography
- Copy button next to each prompt
- Organised by use case
- Mobile-friendly

**Structure:**
```
Strategic Prompting Guide
├── Introduction
├── 3 Core Techniques
│   ├── Risk Deep-Dive
│   ├── Reverse Prompting
│   └── AI Debate
├── Business Use Cases
│   ├── Strategic Analysis
│   ├── Risk Assessment
│   ├── Investment Evaluation
│   └── Change Management
└── Advanced Techniques
```

**Also Provide:** PDF backup for offline

**When Used:**
- Exercise 2 (reference during AI exercise)
- Post-workshop (Monday morning at desk)

---

### 4. Executive Prompt Library ⭐ MAKE INTERACTIVE

**Why Interactive:**
- ✅ 1000+ lines = too long to print
- ✅ Need to COPY prompts (main use case)
- ✅ Search by category
- ✅ Filter by use case
- ✅ Customize prompts for your industry

**Format:** Interactive HTML library
- Search bar
- Category filters (Strategy, Risk, ROI, Ethics, etc.)
- Copy button for each prompt
- Customization fields (insert your industry/context)
- Favorites/bookmark feature

**Features:**
```
[Search: "risk assessment"]

Results (5 prompts):

┌─────────────────────────────────────────┐
│ Risk Deep-Dive for AI Investments       │
│                                          │
│ You are a strategic [INDUSTRY] ▼        │
│ consultant...                           │
│                                          │
│ [📋 Copy Prompt] [⭐ Favorite]          │
└─────────────────────────────────────────┘
```

**Also Provide:** Downloadable markdown (for those who prefer files)

**When Used:**
- Post-workshop (primary use is Monday morning)
- Quick reference tool for executives
