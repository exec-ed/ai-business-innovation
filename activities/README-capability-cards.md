# AI Capability Cards - README for Facilitators

## Overview

The AI Capability Cards are designed for **Exercise 1: AI Tech Radar** (9:45-10:30 AM, 45 minutes). They help participants map their organization's AI capabilities using the AI Transformation Matrix.

---

## Two Formats Available

### 1. Digital/Online Version
**File**: `ai-capability-cards.md`
- **Use for**: GitHub Pages, online viewing, projector display
- **Format**: Single markdown file with all 12 cards
- **Best for**: Remote workshops, digital-first sessions

### 2. Printable Card Version  
**File**: `ai-capability-cards-printable.md`
- **Use for**: In-person workshops (RECOMMENDED)
- **Format**: 4 cards per A4 page (landscape)
- **Best for**: Physical manipulation, tactile engagement

---

## Recommended Setup: Physical Cards

### Why Physical Cards Work Better:
✅ **Tactile engagement**: Participants can hold, shuffle, discuss  
✅ **Better collaboration**: Pass cards around table, point at specific ones  
✅ **Visual organization**: Physically placing on matrix clarifies relationships  
✅ **Professional feel**: Mimics design thinking/innovation workshops  
✅ **Takeaway value**: Participants can keep cards as reference  

---

## Printing Instructions

### Materials Needed:
- **Cardstock** (200-300gsm recommended) or heavyweight paper
- **Paper cutter** or scissors
- **Printer** with A4 paper tray
- Optional: **Laminator** for durability

### Print Settings:
1. **Paper size**: A4 (210mm × 297mm)
2. **Orientation**: Landscape
3. **Pages to print**: Pages 1-3 (12 capability cards)
4. **Optional**: Page 4 (4 blank cards for custom capabilities)
5. **Scale**: 100% (do not reduce/enlarge)

### Cutting Guide:
Each A4 page produces **4 cards**:
- Cut along the dashed lines (┄┄┄)
- Each card: ~14.8cm × 10.5cm
- Use paper cutter for clean edges

### Quantity:
- **1 set per table** (4-6 participants share one set)
- For 20 participants (4 tables): Print 12-16 sets
- Keep 2-3 extra sets as backup

---

## Setup on the Day

### Room Setup (30 min before):
1. **Print and cut cards**: 1 set per table (12 cards each)
2. **Prepare large matrix**: Draw AI Transformation Matrix on flipchart (1m × 1m)
3. **Alternative**: Print matrix on A3 and place on each table
4. **Materials per table**:
   - 1 set of capability cards (12 cards)
   - 1 AI Transformation Matrix reference sheet
   - Sticky notes (for placing cards)
   - Markers

### Storage:
- Keep each set in a **labeled envelope** or zip-lock bag
- Include: 12 capability cards + 1 matrix reference sheet
- Label: "AI Capability Cards - Table [X]"

---

## Exercise Flow (45 minutes)

### Phase 1: Distribution & Review (10 min)
- **Distribute cards** to each table
- Participants **browse all 12 cards** individually
- Read technology, examples, questions

### Phase 2: Group Mapping (20 min)
- Tables **discuss** which capabilities their organization has/needs
- **Place cards** on the matrix based on:
  - Horizontal: Process ↔ Strategic
  - Vertical: Incremental ↔ Transformational
- Use the "MATRIX HINT" on each card as guidance
- Can use same card multiple times if capability spans quadrants

### Phase 3: Gap Analysis (10 min)
- **Identify gaps**: Which quadrants are empty?
- **Discuss**: 
  - Why are certain quadrants over/under-represented?
  - What's the strategic implication of gaps?
  - Which capability should we prioritize?

### Debrief (5 min)
- What surprised you about your AI portfolio?
- Are you over-invested in one quadrant?
- What's the most critical gap?

## Customization Options

### Add Industry-Specific Cards:
Use the **blank cards** (Page 4) to add:
- Retail: "Inventory Optimization AI"
- Healthcare: "Clinical Decision Support"
- Manufacturing: "Predictive Maintenance"
- Finance: "Algorithmic Trading"

Participants can fill these out during the exercise.

### Color Coding:
Print quadrants in different colors for visual clarity:
- **Blue cards**: Optimize (Process/Incremental)
- **Green cards**: Enhance (Strategic/Incremental)
- **Orange cards**: Revolutionize (Process/Transformational)
- **Purple cards**: Transform (Strategic/Transformational)

## Troubleshooting

### "The cards don't fit our organization"
→ Use blank cards to create custom capabilities  
→ Participants can modify examples to match their industry

### "We don't know where to place a card"
→ That's okay! Placement is subjective  
→ The discussion about placement is the learning moment  
→ If uncertain, place between two quadrants

### "We have too many cards in one quadrant"
→ That's valuable insight! It means portfolio imbalance  
→ Ask: "What's the risk of over-investing in [quadrant]?"

### "We don't have any of these capabilities yet"
→ Perfect! The exercise reveals what's possible  
→ Shift focus to: "Which should we start with?"

## Tips for Success

### Before the Workshop:
✅ Test print 1 page to verify layout  
✅ Cut 1 sample card to check size  
✅ Laminate 1 set to test durability (if reusing)

### During the Workshop:
✅ Let participants physically move cards (not just point)  
✅ Encourage debate about placement (it's subjective)  
✅ Take photos of final matrices for later discussion

### After the Workshop:
✅ Let participants keep their card sets  
✅ Share digital version (ai-capability-cards.md) via email  
✅ Collect feedback on which cards were most/least useful
